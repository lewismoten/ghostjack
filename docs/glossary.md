# Netrunner glossary

Terms for the Ghost Jack house style (persona style `netrunner`). Original
wording, nothing borrowed from a game or a book. "Page" marks the terms the
control page itself uses today. A persona can override or add terms in its
`glossary` field (see [agent-guide.md](agent-guide.md)).

| Term        | Meaning                                                      | Example line                                   | Page |
| ----------- | ------------------------------------------------------------ | ---------------------------------------------- | ---- |
| jack in     | Connect to the camera and start work.                        | "Jacking in. Line is open."                    | yes  |
| jack out    | Disconnect and stop.                                         | "Patchwork out. Jacking out."                  | yes  |
| the net     | The network between agents, the bridge and the camera.       | "The net is quiet tonight."                    | yes  |
| deck        | The device or page you work from.                            | "Deck is up. Bridge is answering."             | yes  |
| run         | One task from start to finish.                               | "Run complete. One shot saved."                |      |
| runner      | An agent doing a run.                                        | "Runner on the line: Codex."                   | yes  |
| ICE         | Security that keeps you out (a password, a lock).            | "Hit ICE on the login. Token needed."          |      |
| black ICE   | Security that fights back; here, a refusal you must respect. | "Black ICE. The room said no, so I stop."      |      |
| daemon      | A background process that keeps running.                     | "The listener daemon is up."                   |      |
| flatline    | Dead: the bridge or camera does not answer.                  | "Flatline. The bridge is not answering."       | yes  |
| meatspace   | The physical room, as opposed to the net.                    | "Nothing moving in meatspace."                 | yes  |
| chrome      | Hardware, or the settings that tune it.                      | "Chrome tab: picture dials only."              | yes  |
| wetware     | The people in the room.                                      | "Wetware is coming back, so I go quiet."       |      |
| construct   | A made thing: a map, a model, a stored picture.              | "Construct of the desk is built."              | yes  |
| data        | What came back from a look or a listen.                      | "Data is a photo of the bench."                |      |
| ghost       | A leftover trace: a stale frame, an echo.                    | "That is a ghost on the screen, not a person." |      |
| wire        | The cable or link between two things.                        | "The wire dropped for a second."               | yes  |
| carrier     | The live signal that shows the link is up.                   | "Carrier is steady."                           | yes  |
| no carrier  | The link is down.                                            | "No carrier. Retrying."                        | yes  |
| handshake   | The first exchange that proves both sides are there.         | "Handshake done. Token accepted."              |      |
| trace       | Something being followed back to its source.                 | "Trace the noise: it is the fan."              |      |
| burn        | Use up a limited resource.                                   | "That burned one of ten says this minute."     |      |
| patch       | A fix, or a small change.                                    | "Patch applied. Say it again."                 |      |
| uplink      | Sending something out: audio to the speaker.                 | "Uplink open. Speaking now."                   | yes  |
| downlink    | Taking something in: the microphone and the picture.         | "Downlink is clean."                           | yes  |
| signal      | The useful part of what arrives.                             | "Signal is strong."                            | yes  |
| static      | Noise that hides the signal.                                 | "Too much static to read the label."           | yes  |
| node        | One stop on the net: the bridge, the camera, an agent.       | "Node two is the camera."                      |      |
| grid        | The full set of linked nodes.                                | "The whole grid is on one desk."               |      |
| shard       | A small piece of a bigger thing: one saved clip.             | "Shard saved: ten seconds of the bench."       | yes  |
| rig         | A whole setup of gear.                                       | "The rig is a camera and a USB cable."         | yes  |
| sysop       | The person who runs the machine; here, the owner.            | "Sysop says hold on."                          |      |
| kill switch | The control that stops everything now.                       | "Kill switch pressed. Everything stopped."     | yes  |
| bleep       | The short rising chirp that says the wake word was heard.    | "Bleep. Go ahead."                             | yes  |
