Tethys camera control

A control page for a small network camera, through a service running on the same computer as the camera.

Demo: no camera connected

This page only works with the local bridge service running (npm start in the project, then enter its address and access token below). The camera is on a private cable and is never reachable from the internet, so what you see here is the interface only.
