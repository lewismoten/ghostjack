TETHYS // CAMERA

Control page for a small network camera, through a service on the same computer.

DEMO // no camera connected

This page only works with the local bridge service running (npm start in the project, then enter its address and access token below). The camera sits on a private cable and is never reachable from the internet, so this is the interface only.
